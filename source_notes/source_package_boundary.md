# Source-package boundary

This Paper 1 proof-of-concept package is derived from the uploaded transition-matrix manuscript-engineering materials but is intentionally refactored as a non-medical XAI methodology paper. ECG-specific framing, datasets, ontology language, and clinical claims are excluded from the manuscript body. The ECG material is reserved for a separate application paper.

The AwA2 representation matrix is used internally as a cached trained-representation artifact so that the experiments are reproducible in this environment. The manuscript body follows the conceptual wording specified in the implementation plan: matrix A is obtained through the trained ResNet-101 representation pipeline.
